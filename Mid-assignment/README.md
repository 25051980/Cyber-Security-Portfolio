# Mid Assignment – Software Development

## Academic Context
This project is a mid-term assessed assignment for the Software Development
module of the MSc in Cyber Security.

## Project Overview
A web-based application developed using HTML, CSS, and JavaScript, featuring
separated public and administrative areas. The project focuses on clean
structure, maintainability, and foundational secure coding practices.

## Project Structure
- `admin/` – Administrative interface
- `home/` – Public-facing interface
- `css/` – Application styling
- `js/` – Client-side logic
- `data/` – Application data
- `images/` – Static assets
- `script.js` – Core application logic

## Software & Security Principles Applied
- Separation of concerns
- Modular organisation
- Input handling and validation
- Role separation (admin vs public)
- Defensive programming practices

## Technologies Used
- HTML
- CSS
- JavaScript

## Documentation & Media
- `Final draft.pdf` – Academic report
- `apresentacao.md` – Presentation material
- `VIDEO/` – Demonstration of the application

## Ethical Statement
This project was developed in a controlled academic environment for educational
purposes only. No real-world systems or personal data were involved.
