# Mid Assignment – Software Technologies

## Overview
This mid-term assignment was developed as part of the **Software Technologies** module.
The objective of the assignment was to design and implement a software solution following
good programming practices, modular design, and clear documentation.

## Description
The project demonstrates core software development principles, including:
- Structured and modular code design
- Use of appropriate data structures
- Clear separation of concerns
- Readable and maintainable code

The solution was implemented with a focus on correctness, clarity, and extensibility,
rather than complexity.

## Technologies Used
- Programming language: Python
- Development approach: Object-Oriented Programming (OOP)
- Coding standards: PEP 8
- Version control: Git / GitHub
