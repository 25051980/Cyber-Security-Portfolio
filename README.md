This section of my **Cyber Security Portfolio** contains coursework and assessed projects completed for the *Software Technologies* module.

The module focuses on the fundamentals of software development, including program design, implementation, testing, and evaluation, with an emphasis on writing clean, maintainable, and well-structured code.

- Understanding the software development lifecycle (SDLC)
