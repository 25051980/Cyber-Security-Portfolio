# 🧩 Mid Assignment – Database Systems

This project was developed as part of the **Mid Assignment** for the Database Systems module.  
It focuses on fundamental concepts of relational database design and basic SQL operations.

---

## 📌 Project Overview

The aim of this assignment was to design a simple relational database and demonstrate an understanding of core database principles, including data modelling, table creation, and basic querying.

---

## 🛠️ Technologies Used

- SQL
- MySQL
- Relational Database Design
- Entity–Relationship (ER) Diagrams

---

## 🎯 Learning Objectives

- Understand the principles of relational databases
- Design basic ER diagrams
- Create tables using SQL
- Apply primary and foreign keys
- Perform basic CRUD operations (Create, Read, Update, Delete)
