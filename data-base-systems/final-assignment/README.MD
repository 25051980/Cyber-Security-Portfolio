# 🚀 Final Assignment – Database Systems

This project represents my **Final Assignment** for the Database Systems module.  
It builds upon the concepts introduced in the mid assignment and demonstrates a complete relational database solution, from design to implementation.

---

## 📌 Project Overview

The aim of this assignment was to design, implement, and document a relational database system using industry-standard practices.  
The project focuses on data modelling, normalisation, and the use of SQL to manage and query data effectively.

---

## 🛠️ Technologies Used

- SQL
- MySQL
- Relational Database Management Systems (RDBMS)
- Entity–Relationship (ER) Modelling
- Database Normalisation (1NF, 2NF, 3NF)

---

## 🎯 Learning Outcomes

- Design a complete relational database using ER diagrams
- Apply normalisation techniques to optimise database structure
- Implement databases using SQL
- Define primary and foreign keys to enforce data integrity
- Perform advanced SQL queries using joins, subqueries, and aggregation
- Generate meaningful reports from relational data
