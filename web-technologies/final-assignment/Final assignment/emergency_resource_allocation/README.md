Emergency Resource Allocation System
====================================

A console-based desktop application designed to manage emergency incidents and dynamically assign resources based on priority, urgency, and availability.

Features
--------

- Add incidents with location, emergency type, priority, and required resources

- Add and manage emergency response resources (e.g., ambulance, fire truck)

- Automatically allocate resources based on incident priority and proximity

- Dynamically reallocate resources when higher-priority incidents arise

- Update incident priorities and status in real time

- Close incidents and release allocated resources

- Display incidents and resource allocation in a table-like console format

- Includes unit tests using Python's `unittest` module

- Modular and maintainable codebase following OOP and design patterns (Factory, Observer)

How to Run
----------

1. Ensure Python 3 is installed on your system.

2. Open a terminal and navigate to the project directory.

3. Run the following command:
