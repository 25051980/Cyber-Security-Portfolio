# 🧩 Mid Assignment – Artificial Intelligence

This project was developed as part of the **Mid Assignment** for the Artificial Intelligence module.  
It focuses on the fundamental concepts of Artificial Intelligence, including problem-solving techniques and basic intelligent system design.

---

## 📌 Project Overview

The aim of this assignment was to explore core Artificial Intelligence principles through practical implementation.  
The project demonstrates an understanding of how intelligent agents operate and how AI techniques can be applied to solve structured problems.

---

## 🛠️ Technologies and Tools Used

- Python
- Jupyter Notebook
- Basic Artificial Intelligence algorithms
- Search and problem-solving techniques

---

## 🎯 Learning Objectives

- Understand the fundamentals of Artificial Intelligence
- Represent problems in a form suitable for AI solutions
- Apply basic search strategies
- Develop simple intelligent agents
- Analyse the behaviour and performance of AI-based solutions
