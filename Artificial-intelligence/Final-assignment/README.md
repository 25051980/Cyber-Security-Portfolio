# Final Assessment – Intelligent Agent (Reinforcement Learning)

## Overview
This repository contains the **final assessment** for the Artificial Intelligence module.  
The project focuses on the development of an **intelligent agent using Reinforcement Learning (RL)** techniques.

The aim of this assignment is to demonstrate how an autonomous agent can learn optimal behaviour through interaction with an environment by maximising cumulative rewards.

---

## Project Description
The intelligent agent is trained using Reinforcement Learning principles, where learning occurs through trial and error.  
The agent observes the environment, takes actions, receives feedback in the form of rewards or penalties, and gradually improves its decision-making strategy.

Key concepts explored in this project include:
- Agent–environment interaction  
- Reward-based learning  
- Policy optimisation  
- Exploration vs exploitation  

---

## Objectives
- Design and implement an intelligent agent using Reinforcement Learning  
- Apply AI algorithms to solve a decision-making problem  
- Evaluate the learning performance of the agent  
- Demonstrate understanding of Reinforcement Learning theory and practice
